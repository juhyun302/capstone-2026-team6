# 2027학년도 6월 모의평가 해설 초안

현재 AI 초안 7건(2026-11-02)과 사람이 AI를 활용해 쓴 해설 3건(2026-11-03)이다. 두 묶음은 작성 주체와 방식이 달라 아래에서 구분한다. 10건 모두 AI 보조 정답 대조에서 평가원 정답표 사본과 일치했지만, 사람의 단계별 검산과 최종 라벨 확정은 아직 하지 않았다. 모든 파일은 `검산 전`이며 `사람 검산`은 미작성이다. 검산 완료 전에는 라벨링 입력이나 평가 점수 계산에 사용하지 않는다.

이 실행 당시 공통 10·11번과 미적분 29번은 사용자 선택에 따라 사람 작성용으로 남겨 두었다. 이 세 문항은 아래 2026-11-03에 사람이 AI를 활용해 썼다.

### 작성 방식

- `gpt-6.1-sol`, reasoning effort `high`, Codex CLI `v0.164.0-alpha.11.1`을 사용했다. 모델명은 모델의 자기소개가 아니라 각 실행 로그의 `model` 필드로 확인했다. 별도 모델 스냅샷 식별자는 제공되지 않았다.
- 기존 Aleph 추출 실험의 `gpt-5.5`와 다른 모델이다. 추출 모델이 바뀌면 이 구분도 다시 확인해야 한다.
- 문항마다 새 일회성 세션을 시작했다. 해당 문항의 원문 이미지 1장만 첨부했으며, 미적분 28번에는 원문 그림도 포함했다. 다른 문항의 대화·정답·해설을 전달하지 않았다.
- [해설 초안 프롬프트](../prompts/explanation_draft.md)의 전송부를 그대로 사용하고 문항 ID·과목 범위·이미지 입력 안내를 붙였다. 다른 파일이나 웹의 정답·해설을 찾지 않고 파일을 수정하지 않도록 실행 범위를 덧붙였다.
- 문항별 생성은 총 2회다. 1차 실행은 PowerShell에서 Python으로 문자열을 전달하는 동안 문항 ID·과목 범위·입력 안내의 한글이 `?`로 바뀌었다. 문제 이미지와 파일에서 직접 읽은 프롬프트 본문은 정상이고 정답도 7건 모두 일치했지만, 과목 범위가 정확히 전달되지 않아 정상 입력 실행으로 취급하지 않았다.
- UTF-8 파일로 입력을 준비하고 한글·과목 범위를 확인한 뒤, 문항별 새 대화에서 다시 실행했다. 이 문서의 표와 각 해설 본문은 2차 출력이다. 정답 불일치로 재생성한 문항은 없다. 입력을 고쳤으며 프롬프트 본문은 바꾸지 않았다.
- `해설`·`정답`·`작성자 점검` 본문은 정상 입력 재실행의 출력을 바탕으로 한다. 미적분 28번 1단계의 영어 표현을 `엄격히 증가한다`로 옮겼고, 공통 22번 2·3단계 개수식의 적용 범위를 각각 $t\geq2$, $t\geq5$로 명시했다. 계산 결과·단계 번호는 유지하고 각 파일에 AI 편집 내역을 남겼다. 1차 입력·출력·로그는 `.tmp/explanation-drafts-2026-11-02/`에, 2차 입력·원출력·로그는 그 아래 `corrected/`에 보존했다.
- 생성 세션에는 정답을 주지 않았다. 별도 조정 세션이 초안 생성 후 정답표와 대조했다. 이 대조와 AI 보조 검토는 사람 검산을 대신하지 않는다.
- `사람 검산`은 전부 미작성이고 모든 파일의 상태는 `검산 전`이다. `evalset.jsonl`의 기대값·상태·split은 변경하지 않았다.

### 작성 방식과 변환 상태

- 활용한 모델은 `gpt-6.1-sol`, reasoning effort `high`, 도구는 Codex CLI `v0.164.0-alpha.11.1`이다. 모델명은 실행 로그의 `model` 필드 기준이다.
- 문항별로 별도 일회성(ephemeral) 세션에서 한 번씩 생성했다. UTF-8 파일로 정상 입력을 전달하고 해당 원문을 자른 이미지 1장을 제공했다. 정답은 생성 세션에 주지 않았으며, 초안 생성 후 별도로 정답표와 AI 보조 대조했다.
- 작성자 로컬 도구인 `해설생성기`의 `21_해설작성_매뉴얼.md`와 해당 과목 스타일·묶음 가이드에 따라 작성했다. 기존 7건의 번호 붙인 단계 형식과 달리, 해설생성기에 넣는 본문 형식으로 보존한다. 이 3건에는 기존 `explanation_draft.md`의 전송부를 적용했다고 기록하지 않는다.
- 입력·원출력·실행 로그는 Git에서 제외되는 `.tmp/explanation-generator-2026-11-03/`에 보존한다. 해설생성기의 원생성·변환 파일은 저장소 밖 작성자 PC에 둔다.
- 기존 생성기 스크립트로 개별 HWPX·PDF 각 3개, 문제 PNG 3장·해설 PNG 4장, 합본 HWPX·PDF를 만들었다. 합본은 문제 3쪽과 해설 2쪽이다. 한컴 수식 재계산과 ZIP/XML 검사를 통과했으며, PNG와 합본 PDF에서 문항 번호·수식·내용 잘림을 확인했다.
- 최초 변환에서 발견한 문제 번호 표시 오류를 새 입력 HWPX에서 수정하고 변환을 다시 실행했다. 번호 시작값을 10·11·29로 맞추고 중복 미주 참조표식만 인쇄에서 숨겼다. 해설 생성은 문항별 1회이며 변환 재실행과 구분한다. 생성기 스크립트·템플릿은 수정하지 않았다.
- 미적분 29번은 폭이 긴 수식 2곳의 등호 앞에서 줄만 나눴다. 계산 내용은 유지했으며, 생성 후 AI 보조 검토를 각 해설의 작성자 점검에 별도로 기록했다.
- 합본 PDF와 편집용 합본 HWPX에는 전사한 문제와 해설이 들어 있어 작성자 PC에만 두고, 공개 저장소에는 문제 원문을 추가하지 않았다.
- 세 문항 모두 `사람 검산`은 미작성, 상태는 `검산 전`이다. AI 보조 정답 대조는 사람의 풀이 검산을 대신하지 않는다. `evalset.jsonl`의 기대값·상태·split과 라벨은 변경하지 않았다.
